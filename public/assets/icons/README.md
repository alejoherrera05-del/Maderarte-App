# Iconos de interfaz

La mayor parte de los SVG de esta carpeta proviene de Phosphor Icons, peso regular, bajo licencia MIT.

Fuente: https://github.com/phosphor-icons/core

`house.svg` es un icono geométrico simple creado para la navegación interna de Maderarte App.

Estos recursos son iconos de interfaz y no forman parte de la identidad gráfica de Maderarte.
