# Ajuste de recibos: pantalla y media carta

Base: df44db79e4cb5d705bc9e7614e9f9d9b060b3124. Rama: fix/receipt-layout-half-letter.

El propietario solicita corregir la arquitectura visual de abonos para integrarla con las pantallas existentes de Maderarte y un recibo horizontal media carta (215.9 × 139.7 mm).

Se conserva el recorrido vigente de HomeEasy abono.html (búsqueda, cuenta, historial, captura, confirmación), adaptando por instrucción del propietario el encabezado, tipografía, superficies y controles a Pedido/Cotización. El PDF utiliza la identidad documental aprobada con composición adecuada al formato horizontal.

La muestra contiene solo datos ficticios explícitos, se genera con el mismo renderizador del recibo en el dominio oficial y no crea clientes, OP, pagos, consecutivos ni archivos en Drive. El modo comercial permanece en preparación. Validación automática en GitHub; revisión visual en app.maderartepopayan.com.
