# OP: composición aprobada

El propietario eligió el modelo visual 3 el 9 de septiembre de 2026: selector de muebles, detalle fotográfico central y recorrido lateral grafito con Maddy. El encabezado se adapta al claro de la aplicación y usa sus recursos de marca aprobados. Base GitHub: 472b86dfa457c66ba1514a019360d8fdb1b9fe5c.

Las fotografías se leen mediante la API autenticada, sin inventar fotos de productos. Un mueble sin referencias lo indica. Los hitos mantienen la distinción entre disponibilidad, separado, solicitud, fabricación y despacho; no se declara confirmación del proveedor sin registro. Se conservan documentos, abonos, remisiones y datos del cliente. En móvil se apilan selector, detalle y recorrido.

Implementación y verificación visual en curso. No cambia el backend ni se envían mensajes.
