# Garantías: un expediente desde el reporte

Garantías tendrá acceso propio desde Inicio, junto a Clientes, Producción y Agenda. Nueva garantía busca OP por cliente, identificación o número, selecciona un mueble entregado y registra el reporte. La visita, la recepción y la solución en domicilio conservan el mismo expediente. Una visita realizada no resuelve automáticamente el caso.

La OP abre Garantías con cliente/mueble ya seleccionados. Agenda conserva el ID del caso y vuelve a él. Los expedientes previos siguen consultables. La recepción y atención generan su comprobante después de registrar el hecho correspondiente; un reporte pendiente no emite una recepción ficticia.

Validación prevista: selección entre varias OP y muebles, continuación del mismo caso, reintentos sin duplicados, contexto Agenda y pantallas 1440/390/320. Sin movimientos comerciales sintéticos en producción.
