# Identidad visual

- El nombre se escribe `MADERARTE`, siempre en mayúsculas.
- El wordmark oficial usa Algerian; el repositorio no distribuye el archivo de fuente.
- La paleta operativa combina naranja/cobre, dorado, negro, blanco y grises fríos.
- El tema claro es la experiencia principal.
- No se usan fondos crema, texto diminuto, exceso de vidrio o estética de presentación.
- El PNG original aprobado permanece protegido en Drive y no se publica en esta fundación.
- Los derivados oficiales se incorporarán únicamente después de revisión y aprobación expresa.
- No se crean emblemas alternativos sin revisión y aprobación expresa.
