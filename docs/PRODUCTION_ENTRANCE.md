# Producción — telón de marca y revisión con OP

El propietario solicita el mismo telón aprobado de Clientes, Abonos y Remisiones para Producción. Reutilizar maddy-entrance.css y createEntrance, con la misma tipografía del sistema, gris y base grafito de ancho completo. Maddy mide una pieza de madera con un metro: identidad animada, gesto dirigido a la tarea y pose natural.

El telón cede al formulario al escoger una OP y reaparece al volver a buscar. El formulario conserva su lógica de preparación al proveedor.

Aceptación: crear o reutilizar una OP ficticia en el ensayo aislado del propietario y abrir Producción con el contexto prueba explícito. No se crea una venta comercial, no se envían mensajes al proveedor ni se limpia el ensayo antes de que el propietario pueda verlo. Capturas responsive en GitHub y verificación en el dominio habitual.
